# Kali Linux VirtualBox Lab Setup

A walkthrough detailing the installation and initial configuration of Kali Linux inside Oracle VirtualBox for security testing and learning under the NetworkWalks intership. This is week 1st project. 

---

## Overview
- **Host OS:** Windows 
- **Hypervisor:** Oracle VirtualBox
- **Guest OS:** Kali Linux (64-bit)

---

## Prerequisites
- [Oracle VirtualBox](https://www.virtualbox.org/) installed
- [Kali Linux Installer / Pre-built VM ISO](https://www.kali.org/get-kali/) downloaded

---

## Setup Instructions

1. **VirtualBox Installation:** Installed Oracle VirtualBox on the host machine.
2. **VM Creation:** Allocated CPU cores, RAM, and dynamic virtual hard disk space for Kali Linux.
3. **OS Deployment:** Mounted the Kali Linux ISO into VirtualBox and completed the base installation.
4. **First Boot:** Booted into the desktop environment and verified network connectivity.
